# Mai's Cozy House — сайт хомстея в Сапе

Сайт семейного хомстея **Mai's Cozy House** в деревне Та Ван (Сапа, Вьетнам):
проживание с видом на рисовые поля, треккинги с гидами и культурные туры.
Бронирование идёт через WhatsApp, на сайте выводится живой рейтинг Booking.com.

**Стек:** Next.js 14 (App Router) · Tailwind CSS · Framer Motion · SSG

## Возможности

- Адаптивный лендинг (mobile-first), тёплая палитра cream / forest-green / gold
- **Каталог туров** с динамическими страницами `/tours/[slug]`: маршрут по дням,
  списки «входит / не входит», боковая панель брони, галерея, похожие туры (SSG)
- **Галерея** masonry с увеличением при наведении и лайтбоксом
  (навигация с клавиатуры: `Esc` / `←` / `→`)
- **Отзывы** со звёздным рейтингом и сводной оценкой
- **Форма контакта**, которая собирает готовое сообщение для WhatsApp
- Плавающая кнопка WhatsApp с анимацией пульсации
- Анимации появления секций при скролле (Framer Motion `whileInView`)
- **SEO:** метаданные и Open Graph для каждой страницы
- Бейдж рейтинга и количества отзывов Booking.com

## Контент в одном файле

Вся информация о бизнесе — в [`data/siteConfig.js`](data/siteConfig.js):
описание, туры, галерея, отзывы, контакты, карта и социальные ссылки.
Компоненты править не нужно.

## Запуск

```bash
npm install
npm run dev          # http://localhost:3000

npm run build        # production-сборка
npm start
```

## Структура

```
app/
  layout.js              # шрифты, метаданные
  page.js                # главная (сборка секций)
  tours/[slug]/page.js   # динамическая страница тура (SSG)
components/              # Header, Hero, About, ToursSection, TourCard,
                         # Gallery, Lightbox, Reviews, Contact, Footer, Icons
data/siteConfig.js       # весь контент и хелперы (ссылки WhatsApp и брони)
public/images/           # фото хомстея, туров и галереи
```

## Деплой

Vercel или любой Next.js-совместимый хостинг. Переменные окружения не требуются.
